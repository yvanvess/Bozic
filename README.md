# Bozic — Mascotte du Mont Jovet

Vidéo d'animation de la mascotte **Bozic**, créée pour Timothée.

- `bozic_mascotte.mp4` : Bozic parle en bougeant les bras, sur fond blanc.
- Phrase : « Bonjour, je suis Bozic, la nouvelle mascotte du Mont Jovet. J'ai été créé par Timothée, le beau blond aux percussions ! »
